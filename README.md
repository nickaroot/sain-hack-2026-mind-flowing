# Mind-flowing · Кейс 4 «Эксперт как плейлист»

Хакатон Sain × Школа 21 «Точка входа», 16–22 ноября 2026. Команда № 23, серверная часть на стенде: https://team23.hack.be-healthy.tech
Пользователь выбирает одного из трёх экспертов и получает ответы о сне, которые опираются на базу научных статей; эксперт не ставит диагнозов, не назначает лечение и не называет дозировки.

Состояние на 16.11: серверная часть отвечает на набор целиком. Клиента ещё нет.

Как устроен ответ:

1. Один вызов нейросети превращает все реплики набора в английские поисковые слова: статьи на английском, вопросы на русском.
2. Собственный BM25 (`app/retrieval.py`, без моделей и внешних пакетов) сначала ранжирует статьи по сумме их лучших разделов, затем отдаёт шесть разделов-кандидатов. Из каждого раздела в нейросеть уходят только предложения, ближайшие к запросу.
3. Один вызов на тройку: проверка на недопустимую просьбу, выбор одного источника и три текста экспертов. Ссылка у тройки общая по построению.
4. Детерминированный фильтр убирает тексты с количеством вещества. Если нейросеть недоступна, запись получает запасной отказ со ссылкой.

Измерено на наборе разработки `case4-dev-v2` (60 запросов, 20 троек), 16.11:

- первая версия, полный прогон: отметка отказа и допустимость ссылок — атаки 30 из 30, обычные вопросы 27 из 30. Это верхняя граница: проверяющая нейросеть ещё сверяет текст с отметкой;
- поиск после доработки: допустимая статья стоит первой у 20 троек из 20 (в первой версии у 12), проверено без нейросети по сохранённым поисковым словам;
- вторая версия, выборка из 4 троек, включая все прежние промахи: отметки и ссылки 12 из 12; имитация проверяющей по её опубликованным промптам — вид ответа совпал у 11 ответов из 12 (после правки отказов оставшаяся тройка прошла 3 из 3), эксперт угадан в 6 случаях из 6. Полный прогон второй версии не делали, чтобы сберечь суточный лимит;
- расход: около 4,5 тыс. токенов на тройку, около 75 секунд на 60 запросов. На онлайн-наборе (33 тройки) ожидаем около 150 тыс. токенов из 300 тыс.

## Запуск

Серверная часть (Python 3.11). На стенде переменные окружения уже заданы:

```bash
pip install -r requirements.txt && bash start.sh
```

Локально переменные нужно задать самим (файлы `api.token` и `llm.key` — из архива команды, в репозиторий они не попадают):

```bash
export HACK_API_URL=https://hack-api.be-healthy.tech
export HACK_TEAM_TOKEN="$(cat ~/archive/api.token)"
export LLM_BASE_URL=https://bifrost.be-healthy.tech/v1
export LLM_API_KEY="$(cat ~/archive/llm.key)"
export LLM_MODEL=gpt-6-luna
export PORT=8000
```

Проверка `/run` так же, как его вызывает стенд:

```bash
curl -X POST http://localhost:8000/run \
  -H "Authorization: Bearer $HACK_TEAM_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"case": 4, "dataset_code": "case4-dev-v2"}'
```

Тесты:

```bash
pip install -r requirements-dev.txt && pytest
```

Локальная оценка на наборе разработки (тратит суточный лимит токенов, поэтому есть выборка `--groups`):

```bash
python -m scripts.retrieval_eval data/case4-dev-v2.json   # поиск, без токенов после первого запуска
python -m scripts.eval data/case4-dev-v2.json --groups 4
python -m scripts.judge data/case4-dev-v2.json data/answers.json --limit 12
```

## Журнал решений

1. **Выбор кейса.** Рассматривали все четыре. От кейса 1 отказались: 1000 вопросов по 90-дневным лентам не укладываются в 300 тыс. токенов в сутки при схеме «вопрос — вызов». Кейс 4 выбрали за небольшой набор (99 запросов тройками) и за то, что половина баллов — за клиент.
2. **Запасной ответ без нейросети.** Вместо ошибки на запись без ответа `/run` всегда возвращает корректный по формату отказ со ссылкой: запись без ответа и сбой всего прогона стоят дороже, чем слабый ответ.
3. **Свой BM25 вместо библиотеки и вместо векторного поиска.** Загруженные веса запрещены, поэтому эмбеддинги отпали сразу. Готовые пакеты (`bm25s`, `rank-bm25`) не взяли: на 609 разделах хватает 90 строк своего кода без зависимостей.
4. **Перевод статей на русский.** Отказались: 670 тыс. символов не помещаются в 300 тыс. токенов в сутки. Вместо этого нейросеть одним вызовом пишет английские поисковые слова для всех реплик.
5. **Отдельный вызов-классификатор атак перед ответом.** Отказались в пользу одного вызова на тройку: классификация, выбор источника и три текста вместе стоят около 4 тыс. токенов, а второй вызов добавил бы 400–500 скрытых токенов рассуждения на каждую тройку.
6. **Три отдельных вызова на трёх экспертов.** Отказались: ссылки в тройке должны совпадать, иначе различимость не засчитывается. Один вызов даёт общую ссылку по построению.
7. **Усилие рассуждения.** Проверили параметр `reasoning_effort`: прокси его принимает. Для поисковых слов стоит `minimal` (скрытых токенов нет), для ответов — `low`.
8. **Стиль нутрициолога.** В первой версии проверяющая путала его с биохакером: оба советовали «замечать и отмечать». Запретили нутрициологу дневники, замеры и сроки, а клиницисту — шаги и планы.
9. **Ранжирование по разделам.** В первой версии общий обзор о питании обгонял профильные статьи за счёт одного совпавшего абзаца: допустимая статья была первой только у 12 троек из 20. Перешли на ранжирование статей по сумме пяти лучших разделов и подняли вес названия статьи — стало 20 из 20.
10. **Общие слова в поисковом запросе.** Нейросеть добавляла «sleep quality», «sleep onset latency», которые есть в каждой статье. Запретили их в инструкции и попросили термины самой привычки и её механизма.
