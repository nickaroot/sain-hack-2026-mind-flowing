# Клиент

Здесь будет клиентская часть кейса 4: экран выбора эксперта и экран разговора с экспертом.

Стек пока не выбран. На финале клиент разворачивают на компьютере организаторов, и он обращается к серверной части на стенде, поэтому адрес сервера должен задаваться настройкой, а запуск — одной командой.
